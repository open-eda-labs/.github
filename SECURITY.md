# Segurança

Este é um laboratório pessoal com dados sintéticos ou públicos. Mesmo assim, reporte problemas em privado.

## Como reportar

1. Use o GitHub private vulnerability reporting, na aba **Security** do repositório afetado, em **Report a vulnerability**.
2. Se a opção não estiver disponível, abra uma issue pedindo contato privado ao dono, @Raphonzius. Não coloque detalhes da vulnerabilidade na issue.

Não publique segredos, credenciais ou dados pessoais em issues, PRs ou comentários. Se encontrar algum no Git, avise pelos canais acima para revogar e remover.
